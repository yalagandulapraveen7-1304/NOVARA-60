NOVARA | ANTARCTIC DIGITAL TWIN

India’s Antarctic Research Stations (Maitri & Bharati) — Complete Technology Stack

Category Technology How it is used
Data Collection & Storage Python 3.11 Core execution language for the digital twin backend, microgrid dispatch models, and API orchestration.
Pandas + NumPy Cleans, transforms, and processes real-time synoptic polar climate data, power curves, and high-frequency sensor readings.
MQTT / WebSocket Streams Streams sensor, generator, solar, and katabatic wind generation data in real time with low latency.
Pydantic v2 Enforces strict data schemas, fault injection validation, and parameter constraints for all incoming telemetry.
PostgreSQL / SQLite (WAL) Stores time-series telemetry, meteorological forecasts, alert history, and optimization dispatch schedules.
Predictive Intelligence & Diagnostics LightGBM Forecasts station electrical load, renewable output under cloud cover, and equipment failure risk.
Scikit-learn (Isolation Forest) Flags abnormal sensor drift, alternator stator overtemperature, and unusual microgrid voltage deviations.
Survival Analysis (RUL) Predicts Remaining Useful Life and maintenance windows for primary diesel generators and BESS battery banks.
Groq LLM Advisory Copilot Generates actionable operational guidance, fuel conservation advice, and incident response playbooks for station crews.
Simulation & Optimization Engine SciPy + Deterministic Physics Powers the Digital Twin simulation under polar conditions (building heat loss at −41°C, katabatic wind cut-out, BESS cold derating).
Google OR-Tools / PuLP Solves the Mixed-Integer Linear Program (MILP) to identify the most fuel-efficient dispatch schedule while guaranteeing N+1 redundancy.
CasADi / MPC Control Runs Model Predictive Control to dynamically modulate battery charge/discharge and diesel compensation in real time.
3D Digital Twin & Visualization Three.js (@react-three/fiber) Renders the interactive 3D digital twin of Maitri and Bharati stations, dynamic katabatic blizzards, and building interiors.
React 19 + TypeScript Powers the station mission-control dashboard with strict type safety, modular panels, and responsive desktop/tablet layouts.
Recharts + Tailwind CSS Displays real-time energy flow equations, generation vs load trends, battery state-of-charge, and thermal balance curves.
TanStack Router & Start Delivers high-performance client routing, code-splitting, and fast bundle hydration across viewports.
System Integration & Deployment FastAPI Integrates AI models, Digital Twin physics, and dashboard controls into a high-throughput, documented OpenAPI REST service.
Production CORS Engine Secures cross-origin requests between the Vercel edge frontend and Render backend with dynamic origin regex matching.
Vercel Hosts and serves the 3D Digital Twin frontend globally with sub-second asset delivery via the Build Output API.
Render Runs the persistent Python FastAPI backend, mathematical simulation loop, and automated health checks.
Docker Packages dependencies and models into a lightweight container for consistent, repeatable deployment.
